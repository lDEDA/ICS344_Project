## Issues Faced

During our project, we encountered several hurdles:

* Our initial setup used an ARM-based MacBook running Kali Linux, but the virtual machine’s allocated storage filled rapidly during installation. We expanded the disk capacity and reallocated resources before proceeding.
* Metasploitable3 exhibited compatibility issues in our environment, so we reverted to Metasploitable2 to maintain progress without further delay.
* When deploying Splunk Enterprise, we discovered it only supports x86 architectures. To address this, we switched to a Windows-based host and restarted the Splunk installation from scratch.
